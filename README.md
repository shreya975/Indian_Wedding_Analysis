# 📖 Project Overview

Planning a wedding involves managing multiple expenses such as venue, decoration, entertainment, photography, clothing, invitation cards, and gifts. Understanding how these costs vary across different wedding types and locations can help make informed financial decisions.

This project performs **Exploratory Data Analysis (EDA)** on an **Indian Wedding Dataset** to discover meaningful insights, spending patterns, and trends using Python.

The project includes data preprocessing, cleaning, feature transformation, statistical analysis, groupby operations, pivot tables, and a wide variety of visualizations.

---

# 🎯 Objectives

- Perform data cleaning and preprocessing.
- Analyze wedding spending across different wedding types.
- Compare expenses across multiple wedding locations.
- Study decoration and entertainment preferences.
- Analyze photography, invitation, and gift expenses.
- Identify spending trends using statistical visualization.
- Generate business insights from wedding data.
